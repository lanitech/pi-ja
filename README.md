# pi-ja

オープンソースのコーディングエージェント [Pi](https://pi.dev) を日本語で使うためのパッケージです。

[English](README.en.md)

## できること

- **日本語で作業するルールをシステムプロンプトに追加**：回答は日本語、新しく書くコメントは日本語、コミットメッセージは `fix(scope): 日本語の要約` の形、日付は YYYY-MM-DD、など。プロジェクトの `AGENTS.md` やユーザーの指示がある場合はそちらを優先します。
- **画面表示の日本語化**：起動ヘッダー、作業中の表示、思考ラベル、ステータス行、操作一覧を日本語で表示します。
- **日本語の設計書スキル（ja-design-docs）**：要件定義書・画面一覧・データ設計の雛形で、開発前の設計書を作ります。

スラッシュコマンドは英語のままです。

## インストール

```bash
pi install npm:@lanitech/pi-ja
```

プロジェクト単位で入れる場合は `-l` を付けます。

```bash
pi install -l npm:@lanitech/pi-ja
```

## 使い方

入れたあとは Pi を起動するだけで日本語モードになります。

| コマンド | 内容 |
| --- | --- |
| `/ja` | 今の状態を表示 |
| `/ja off` / `/ja on` | 日本語モードを切り替え（セッションに保存されます） |
| `/ja keys` | 操作の一覧を日本語で表示 |
| `/ja rules` | システムプロンプトに追加しているルールを表示 |

設計書を作るときは、そのまま頼むか、スキルを指定して呼び出します。

```text
/skill:ja-design-docs 予約管理システムの要件定義書を作って
```

## 日本語にならないところ

Pi 本体のメニュー、`/` コマンドの説明、設定画面などの文言は、拡張の仕組みでは置き換えられないため英語のままです。

## 動作環境

Pi 1.0 以降で動作を確認しています。
